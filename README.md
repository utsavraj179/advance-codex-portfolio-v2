## 🚀 About

A space-themed developer portfolio with a **red / orange** glow. It mixes a few well-placed 3D scenes with smooth scroll animations, so it looks premium and stays fast.

> *"7 years of Minecraft, 4 years on Discord, 3 years of development."*

| 🕹️ Minecraft | 💬 Discord | 💻 Development |
| :---: | :---: | :---: |
| **7+ years** | **4+ years** | **3+ years** |

---

## ✨ Features

| | Feature | Details |
| --- | --- | --- |
| 🖥️ | **3D Retro PC** | Orbit-rotatable computer in the hero, generated in code (no model files) |
| ⭐ | **Starfield** | 5,000 procedural stars drifting behind every section |
| 🪐 | **Lava Planet** | Slowly rotating planet in the contact section |
| 🎴 | **Tilt Cards** | Glare + parallax on disciplines and projects |
| 🧩 | **Tech Chips** | Floating, hover-lift animated stack badges |
| 🌊 | **Scroll Reveals** | Smooth fade-ins, progress bar and active nav highlighting |
| 📬 | **Contact Form** | Opens your mail app, plus copy-email and Discord invite |
| 📱 | **Responsive** | Works on mobile, tablet and desktop, and respects reduced motion |

        ├── Navbar · Hero · About · Experience

            └── Stars.jsx      # starfield

## ⚡ Getting Started

```bash
# 1. Install dependencies
npm install

# 2. Start the dev server  →  http://localhost:5173
npm run dev

# 3. Build for production
npm run build

# 4. Preview the build
npm run preview
```

---

## 🎨 Customize

| What | Where |
| --- | --- |
| Name, intro, experience, tech, projects | `src/constants/index.js` |
| Colors (`accent` red, `flame` orange) | `tailwind.config.js` and `src/index.css` |
| 3D scene colors | `src/components/canvas/*.jsx` |

---

## 🌐 Deploy

1. Push the project to GitHub.
2. Import the repo on [Vercel](https://vercel.com).
3. Vite is detected automatically, so just hit **Deploy**.
